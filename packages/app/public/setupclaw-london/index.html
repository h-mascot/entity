FAQ

      

        
Is this for non-technical teams?
Yes. Technical teams benefit too, because their time is usually better spent shipping product than wrestling OAuth goblins.

        
Is it secure?
The default setup is governed. Sensitive sends, financial actions, destructive operations, and external commitments require approval.

        
Do I need a Mac Mini?
Not necessarily. The right host depends on what you want the agent to do, what data it needs, and how much local control you want.

        
What happens in the afternoon?
We choose the first useful workflow, connect one channel, wire three tools, set the guardrails, run a real task, and hand over the proof.

Start with the first useful slice. Multi-week architecture diagrams before first proof are how agents go to die wearing a tiny consultant lanyard.
