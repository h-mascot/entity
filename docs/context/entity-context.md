# Entity Context Pointer

`CONTEXT.md` at the repository root is the canonical Entity project-start
context.

Read order for Entity work:

1. `CONTEXT.md`
2. `docs/plans/ACTIVE_PLAN.md` when a multi-step task is already in progress
3. Task-specific docs under `docs/` only when relevant

This file intentionally avoids duplicating runtime paths or deployment facts.
Private deployment details belong in clearly internal operator docs, not public
defaults or generic setup instructions.
