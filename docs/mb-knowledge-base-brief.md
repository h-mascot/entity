## Problem Statement

### Context
MascotBot (MB) is a multi-agent system with 26+ feature modules (MB-01 through MB-26). Knowledge is currently scattered across:
- Individual agent MEMORY.md files
- Daily notes in multiple locations
- Session transcripts
- Ad-hoc documentation
- Tribal knowledge in Henry's head

### The Problem
1. **No single source of truth** — Knowledge fragmented across files and agents
2. **Discovery is hard** — Finding relevant information requires searching multiple locations
3. **Duplication** — Agents re-research topics already covered elsewhere
4. **Knowledge loss** — Patterns and decisions get buried in daily notes
5. **No sharing** — MB council members can't access each other's learnings

### Impact
- 2-4 hours/week wasted on re-research
- Inconsistent information across agents
- Lost institutional knowledge
- Slower onboarding for new council members

---

## Goals

### Primary Goals
1. **Centralize** all MB knowledge in one searchable location
2. **Enable discovery** across all knowledge sources
3. **Prevent duplication** by surfacing existing knowledge
4. **Facilitate sharing** between MB council members

## Scope

### In Scope
- All MB feature documentation (MB-01 through MB-26)
- Agent memory files (Ada, Spock, Scotty, Zora, Geordi)
- Daily notes aggregation
- Session transcript indexing
- Search and retrieval interface
- Category/tag organization
- Basic access controls (view/edit)

### Out of Scope (Phase 1)
- Real-time collaboration
- Advanced permissions
- External integrations (Notion, Google Docs)
- Mobile app
- AI-powered suggestions (Phase 2)
