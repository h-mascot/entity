HTML Entity MC Context Purpose entity-mc is the standard bootstrap skill for deploying Entity Mission Control helper tooling to crew agents without manual script copying. It packages the working Mission Control helper runtime into one reusable, versioned bundle with a thin installer layer and per-agent manifests. Why it exists Previous deployments relied on copying scripts by hand into agent homes, especially on Mac-hosted agents like Zora. That worked, but created drift risk, weak rollback, and awkward onboarding. entity-mc is the replacement direction: one canonical runtime one thin bootstrap/install skill tiny per-agent manifests idempotent install/update verification and rollback built in Architecture Shared runtime bundle Canonical scripts packaged from skills/entity-mc/source-scripts/: mc.sh mc-auto-pull.sh mc-assign-model.sh mc-build-context.sh mc-stall-check.sh Note: source-scripts/ is the safe staging source (not workspace scripts/ which may contain wrapper stubs after install).
